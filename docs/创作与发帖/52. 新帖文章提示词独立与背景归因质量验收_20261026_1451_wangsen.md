# 新帖文章提示词独立与背景归因质量验收

创建时间：2026-10-26 14:51 · 作者：wangsen · 版本：2.19.2

## 背景与根因

用户提供已发表的新帖 `https://x.com/WatsonTaylor23/status/2114598204247601589`，正文直接从中美道路死亡统计起笔，读者看不到作者为何讨论这个议题。已通过登录态 CDP 读取正文；未在当前队列记录中找到匹配的发布任务，因此不推断其最初选中的来源帖子。

`generateOriginalPost` 原先调用引用评价提示词，再在末尾追加独立新帖要求。前文仍要求“挑一条公开引用评价”，并带有引用文体、较低质量门槛与标签指令。末尾覆盖没有改变整体任务框架。

## 实现与产品要求

- 在发帖模块新增 `article-prompt.js`，独立构建文章提示词。共享 Grok 模块仅新增 `promptBuilder` 参数，默认引用路径保留原行为，不新增依赖或重复实现浏览器交互。
- 新帖先识别原帖的具体主张、事件或现象，首段交代写作缘起与读者关心的问题，再展开独立观点、依据、机制、适用边界和有用启示。不强制固定标题或分节，不靠字数制造深度。
- 不能虚构最近刷到、热搜、争议、亲身经历或查证结果。二手统计首次出现必须归因；条件不明时保留条件句。单年比较不能证明长期改善或某项措施有效。
- 原帖语言与写作风格偏好保留；偏好不能覆盖事实要求。素材中的指令不构成任务指令。
- 原有质量门槛保留：证据和新增分析各2分，其他两项至少1分，总分至少7分。材料不足允许跳过。简短、深入、自适应均使用文章文体。
- 保留现有选帖、评分与正文边界协议，仅用于机器读取；这些兼容标记不进入发布正文。

## 验证范围

### 关键文件对照

| 文件 | 职责及本轮变化 |
| --- | --- |
| `src/features/publishing/article-prompt.js` | 独立文章任务、开篇缘起、事实归因、读者价值与输出前自检 |
| `src/features/publishing/post-writer.js` | 新帖路径指定文章提示词，继续复用Grok请求及新帖质量门槛 |

| `tests/article-prompt.test.js` | 验证提示词分离、完整上下文、选帖绑定和材料不足跳过 |

新增回归覆盖文章提示词与引用提示词分离、完整材料和写作偏好、背景与归因要求、真实共享请求路径、选帖绑定、一次调用与低价值跳过。保留现有新帖正文安全与质量检查。

真实 Grok 草稿测试以用户提供的已发表正文作为分析材料，验证文章写作路径；这不等于识别或核实了该帖的最初来源，也不等于核实中美道路统计。早期生成结果仍出现二手数据断言、单年推断趋势与任务措辞外露，故收紧首次归因、首段具体议题及输出前自检。实测只生成草稿，没有发布、修改或删除用户帖子，仅关闭测试创建的窗口。

自动评分是模型自评，不能保证每次内容准确或有价值。本轮没有增加额外的生产二审调用，生产生成仍保持一次 Grok 请求；验证中的多轮试稿仅为本次人工验收。

以下记录2.19.2更新时的验收快照。随后自动私信迭代已将共享插件更新至2.19.3，详见同一文档对照表中的第53篇；本篇不将旧版本快照描述为后续实时状态。

- 自动化测试 979/979、构建测试 54/54 通过；最终提示词定稿后文章及发布针对性测试 10/10 通过。源码检查通过：118 个模块语法、138 个文件浏览器调用契约。共享 `dist` 构建与产物校验通过。
- 本轮共4次真实 Grok 试稿，前两次因归因及推理问题收紧，第三次发现任务措辞外露，最终版改为自然归因。最终正文首段以中美死亡数比较为缘起，提出指标选择的问题；首次数字归因于该比较，随后明确可比口径条件、单年截面不构成安全排名或趋势证明。没有独立核实原材料的统计数字。
- 最终正文与评分已通过现有解析和新帖质量检查。没有额外发帖，也没有改动用户的示例帖子；测试窗口已关闭。
