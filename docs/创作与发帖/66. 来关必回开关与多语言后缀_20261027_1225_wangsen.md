# 来关必回开关与多语言后缀

创建时间：2026-10-27 12:25；作者：wangsen；本地候选版本：3.3.6。

## 背景与行为

旧评论路径已有互关后缀函数，统一关注队列的设置和后台创作流程未接入。现于“关注队列 → 设置 → Grok 创作与发布”新增“来关必回”开关，默认关闭，设置按账号保存；已保存账号的参与概率、自动发布等设置不改变。

开启后，评论和引用评论生成或处理草稿时使用已有多语言后缀逻辑：中文追加“来关必回”，英文及无对应语言时追加“I follow back.”，西班牙语和葡萄牙语沿用既有译文。正文已有对应互关语句时不重复。文章和旧版独立新帖不追加。关闭时不额外添加；开关不改写已经公开的历史帖子。

先保留基础正文，再追加后缀与引用标签；如果后缀放不进 280 加权字符，保留原文草稿并显示“无法追加来关必回”，不截断正文或自动公开发布。模型质量检查、选帖、参与概率及防重复发布继续生效。

## 实现与验证

- `follow-queue-store.js` 保存 `followBackSuffixEnabled`，缺失字段默认为关闭；局部保存和不同账号互不覆盖。
- `follow-queue-panel.js` 显示简短开关，并在提示中解释适用范围、默认状态、翻译及字数限制。
- `grok-comment.js` 复用现有 `appendFollowBackSuffix` 与加权长度计算，后台在 `follow-queue-runtime.js` 中应用；`baseText` 保留原始生成文本。
- 1,085 项核心测试、54 项构建测试、静态检查和 `dist` 产物校验通过。测试覆盖中英文、西葡文、已有后缀去重、关闭、字数不足草稿保留、后台评论与引用评论以及账号设置持久化。
- 真实 Chrome 内独立测试页面在 390px 窄屏验证默认关闭、开启保存并重开、关闭保存并重开，横向宽度无溢出。测试数据独立于用户账号。
- `dist` 已构建并重载为 3.3.6；实际账号设置入口中开关存在且为关闭，原有创作概率 60%、Grok 与自动发布设置保留。未为本次验收发送新的 Grok 请求或公开帖子。
