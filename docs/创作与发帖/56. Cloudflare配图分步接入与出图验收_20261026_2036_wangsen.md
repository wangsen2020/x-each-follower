## 用户流程

从文章配图入口打开模态弹窗，依次完成登录账号、填写 Account ID、创建 API Token、测试并绑定。每页提供下一步或上一步；账号 ID 不合法时原地提示，Token 使用密码输入。用户在 Cloudflare 官方页面创建 Workers AI 专用 Token，无需域名或部署 Worker。

测试并绑定先验证账号访问，再调用 FLUX.1 schnell 生成图片，解码并裁切为 5:2，全部成功后才写入本地 Dexie 凭据库、清空 Token 输入并显示成功页与测试图。接口可访问不等于绑定成功。

已绑定用户再次打开直接看到连接管理，可解绑或重新绑定。重新绑定在测试成功前保留旧凭据；失败、返回或关闭不替换旧连接。解绑删除本地凭据，不代替用户在 Cloudflare 撤销令牌。运行中的普通出图请求不回写凭据，避免解绑后被在途请求恢复。

## 实现

- `src/features/publishing/cloudflare-cover.js`：官方 REST API 最小适配；Dexie 独立本地存储；测试出图后提交凭据；不向界面返回 Token。
- `src/entries/panel/composables/useCloudflareImages.js`：四步状态、输入校验、可选域名访问权限、忙碌防重、失败重试和重绑管理。
- `src/entries/panel/components/CloudflareImageSettings.vue`：分步弹窗、测试图、键盘焦点管理、窄屏布局。
- `src/manifest.json`：Cloudflare API 可选访问权限，在用户点击测试时申请。

免费额度按账号共享。测试会消耗用量，Free 计划与付费计划超额行为不同，操作前显示说明。参考官方文档：https://developers.cloudflare.com/workers-ai/get-started/rest-api/ 。
