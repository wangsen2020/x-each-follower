# 评价重试全链路反馈与账号核验验收

## 问题与验收标准

用户点击“重试评价”后，后台标签出现并关闭，原页面未说明执行结果。验收要求：点击即有反馈，过程可见，结束显示真实结果；跳过不冒充发布，失败不误报账号变化，已关注结果不回退；明确结束的质量跳过可由用户主动重新评估，未知提交结果仍须先核实。

## CDP 实际链路

在3.2.4点击Yasmina_sm任务的“重试评价”，约49.4秒后结束。任务补全五条缓存不完整的原帖，调用Grok一次，返回quality_skip，未发布。后台返回的summary说明素材未达到质量要求，前端成功分支只刷新列表，丢弃summary；行内仅有“已跳过”，没有原因。这是本轮“闪现后没有动作”的直接证据，不是账号切换。

此前账号误报来自导航后的短暂空身份：3.2.4已增加有界等待，真正账号不符立即阻止，持续未读到身份单独报错。关注与评价执行守卫复用该判断。

## 3.2.5 修复

- 评价过程发送轻量进度事件，仅当前账号、当前活跃手动任务接收；显示核验账号、读取原帖序号、Grok评估、配图及发布核验等实际进入的阶段。
- 处理中隐藏旧评价状态，避免同时显示“已跳过”和“正在执行”；完成时显示返回原因。保存的evaluation.reason在重新打开页面时仍可见。
- 进度监听随面板销毁清理，结果返回后忽略迟到的进度。删除按钮在评价期间禁用，保持“删除”标签，不伪装成另一项正在执行的操作。
- quality_skip属于明确完成，允许用户点击“重新评估”；没有授权自动重复处理。generation_uncertain等不明结果仍阻止重复生成。
