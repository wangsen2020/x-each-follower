# Grok Hook链路复盘与3.7.4发行验收

## 范围与结论

本轮将已集成的粉丝管理、队列恢复、自动取关隔离与创作链路整理为3.7.4。源码、清单、package和锁文件统一为3.7.4；构建仅从src生成dist，发行包只包含dist。

Grok Hook是Grok自动化Webhook通道，仍使用Grok用量。此前“独立Bot额度”是假设，不能以回调HTTP 200或自动化运行成功作为额度生效证据。界面已更名，历史任务内部标识保留。

## 根因与修复

1. 插件绑定新Worker，而自动化固定回调旧Worker，任务位于不同D1导致404。回调应固定为当前连接Worker的/v1/callback；Cloudflare请求头调整与地址一致性分别验证。
2. accepted仅表示派发受理。必须核对同一jobId从受理到生成、回调、completed；不并发重放已生成任务。
3. 引用编辑器错误读取背景回复框：优先实际弹窗，独立编辑页需匹配发送按钮；发送前失败保留草稿，发送结果未知继续核验。
4. 创建生成任务至结果返回之间缺少检查点：先持久化relayJobId再派发，恢复时续查原任务，阻止重复生成。

复用现有Dexie、任务续查与发布核验能力；本轮未增加兼容Worker或另造迁移框架。
