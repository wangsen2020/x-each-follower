# 4.0.0发行与3.11.1撤回

> 创建：2026-10-28 17:53，北京时间。作者：wangsen。本轮为用户明确授权的版本替换发行，独立记录86号；知识库实现及样式排障继续维护82号文档。

## 1. 发行范围与旧版处理

用户要求撤回上一版，发布4.0.0。经GitHub核对，上一份正式Release是3.11.1；3.11.2只是本机样式修复验收构建，没有正式Release。

本次保留3.11.1标签和提交历史，将其公开Release转为草稿，以4.0.0作为正式最新发行；不回退已完成的功能，不覆盖旧标签或替换旧版附件。旧草稿供维护者追溯，不作为公开下载入口。

4.0.0包含3.11.1已有的知识库、就地Bot选择、队列恢复、取关恢复、异常提醒、接入教程和内容过滤，并加入本轮知识库样式修复。

## 2. 本轮修复与根因

- 全局label默认纵向排列，分页与学习设置未明确覆盖方向。现在分页计数、每页、select及按钮水平排列、垂直居中、间距10px；学习设置也明确横排。
- 全局表格首列最小宽度280px影响版本表，造成大面积留白。版本表现在独立定义列宽，radio、状态与操作居中，窄屏时间可换行，经验列表按钮不溢出单元格。
- 弹窗标题、操作和关闭按钮独立布局；窄屏分页占单独一行，关闭按钮保持右上角；移除继承的footer顶部留白。
- 旧验收页漏载全局样式，导致生产环境问题未暴露。验收页现在按生产顺序加载全部5份样式，新增单测锁定样式列表与顺序，并提供实际浏览器几何回归。

## 3. 分支与工作区盘点

- 当前唯一待交付特性为feature/knowledge-ui-polish。本轮已检查改动、README、文档和截图后按标准Git Flow完成特性与发行收尾，不保留已完成的feature/release分支。
- 远程初始只有master和develop，无其他待合入特性分支。
- 主目录仍为346306e的旧游离检出，有两处既有教程归档改动。教程正文与当前正式分支84号文档逐字核对一致，索引差异也是相同补充说明；相应提交已集成。本次不重放旧编号、不覆盖其本地现场。
- 原knowledge-learning工作区的master在发行前保持干净。需要解除生产分支占用时仅切到当前提交的游离状态，不删除工作区或其依赖。
