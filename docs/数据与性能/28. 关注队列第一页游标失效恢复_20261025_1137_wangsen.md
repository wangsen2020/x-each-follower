# 关注队列第一页游标失效恢复

- 日期：2026-10-25 11:37
- 版本：2.14.1
- 范围：关注队列列表读取，不改关注执行和账号证据。

## 根因

待核实等稀疏筛选需要在第一页内部连续扫描多个批次。游标绑定数据库 revision，后台任务更新数据后，后续批次会被存储层拒绝。面板原先只在 currentPage 不等于 1 时恢复，遗漏第一页内部批次；异常路径还遗留扫描状态。该条件和分批扫描在 c4511b2 的 2.0.0 源码整合快照中已经存在，不能据此断言最初引入时间。

## 修复

复用现有 Dexie 查询和分页能力，不引入新的分页库，不取消存储层 revision 校验。返回错误与抛出异常统一覆盖第一页；游标失效后清除分页起点并重新读取，最多自动重试两次，每次丢弃上一轮部分结果。持续变化时显示“队列正在更新，请稍后重试。”，用户手动重试可重新开始。保留请求代次检查，过期筛选响应不能覆盖新筛选。

涉及 src/entries/panel/follow-queue-panel.js、tests/follow-queue-panel.test.js 和统一版本入口。
