# 设置弹窗版本历史与升级日志

创建时间：2026-10-25 03:32，Asia/Shanghai。作者：wangsen。状态：本地实现与 CDP 界面验收完成，尚未提交、推送或发行。

## 需求与边界

在系统设置弹窗增加只读的“版本历史”和“升级日志”入口，让用户查看本机实际经历的扩展安装、版本升级和本地记录迁移过程。当前扩展版本取自统一清单版本。功能开始记录以前发生过的升级无法追溯，不据当前版本推断历史路径；IndexedDB 的原子结构升级仍由 Dexie 管理，不伪造逐步日志。

## 实现

- 后台监听扩展真实 `onInstalled` 事件，持久记录安装或由 `previousVersion` 到当前版本的升级；相同事件去重，忽略浏览器自身更新及同版本事件。
- 既有 `recordData` 迁移入口记录启动、检查点、完成或失败，保留迁移任务标识、进度及错误。日志只保留最近 200 条；版本经历单独保留。
- 版本记录写入采用同一存储键的串行更新，避免后台并发事件互相覆盖。日志写入失败不会阻断数据迁移。
- 设置弹窗的两个入口按需读取数据；当前迁移状态读取失败时，已保存的历史日志仍可查看。弹窗关闭后，过期异步结果不再更新界面。
- 本轮新增功能按版本管理规则，将 `package.json`、`package-lock.json` 和 `src/manifest.json` 同步到 2.13.0。

关键入口：`src/shared/version-history.js`、`src/entries/background/background.js`、`src/entries/panel/components/SystemSettingsDialog.vue`、`tests/version-history.test.js`。
