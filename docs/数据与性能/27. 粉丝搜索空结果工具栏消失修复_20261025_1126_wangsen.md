# 27. 粉丝搜索空结果工具栏消失修复

创建：2026-10-25 11:26 · 作者：wangsen · 版本：2.14.0

## 复现与根因

用户在待回关分类搜索 situ 后列表和输入框消失。当前页面实际读取到输入 sidu，selectionBar.hidden=true、高度0、monitorList.hidden=true。旧 renderMonitorList 使用搜索后的当前页记录数判断整个分类是否为空，导致包含搜索框的工具栏一起隐藏。分页扫描的空页也不等于整个档案无数据。

另外搜索按钮与回车仅重画旧的分页窗口，未调用与 input 相同的记录查询，可能展示与关键字无关的旧结果。

## 修改

已加载页面保持搜索及分页控件可见。无匹配时在列表区域显示提示；存在后续游标时说明当前扫描范围暂无匹配并允许下一页，没有后续页时显示“没有匹配的账号”。空分类仍可展示正常空状态。

输入、按钮及回车统一调用 searchFollowers 和现有 runRecordPageAction，保留加载错误处理；没有引入新的搜索库或重复查询框架。实现位于 src/entries/panel/panel.js 与 follower-empty-view.js。

## 实机验收

在已登录扩展中选择待回关，点击搜索按钮搜索 situ：搜索框可见、宽度220像素、列表提示没有匹配账号。清空输入后回车恢复正常列表。读取本地记录完成查询，没有触发 X 数据采集。回归覆盖空结果、扫描未结束的分页状态以及现有查询错误封装。
