# X 图片原图预览与居中缩放

## 需求与实际图片核验

用户提供 https://x.com/WatsonTaylor23/status/2116595671969206292/photo/1 作为测试入口。X 原生预览请求 https://pbs.twimg.com/media/HV-nEq0aQAAi1wJ?format=jpg&name=4096x4096，实测解码为525×4096；请求 name=orig 同样为525×4096，JPEG响应318423字节。因此该例已经达到X能提供的原图分辨率，主要问题是整张窄长图适应屏幕后只显示约110像素宽。以X原图端点为准，不将“原图”表述为上传前未经平台处理的文件。

新增控件在X原生图片预览左侧图片区域内工作：缩小、百分比、放大、适应窗口、1:1原始尺寸、下载原图。打开预览即按需获取原图；点击下载按钮才保存文件。默认适应窗口，不影响右侧帖子区和原生关闭按钮。原始尺寸使用图片实际像素尺寸；长图可拖动阅读，双击可在适应与原尺寸之间切换，键盘加减与0可操作。

用户实测反馈“滚动滑轮，放大不居中”后，明确改为预览区域中心缩放，不随鼠标落点偏移。拖动后的阅读位置按中心缩放逻辑保留；缩放层使用独立画布，图片自身布局不参与鼠标焦点坐标计算。

## 复用与架构

评估并直接使用 [Panzoom](https://github.com/timmywil/panzoom) 4.6.2、[MIT许可证](https://github.com/timmywil/panzoom/blob/main/MIT-License.txt)，承担缩放、拖动和指针坐标计算。项目新增代码只负责X预览识别、原图请求、事件隔离、控件、资源生命周期与语言适配，不自研等价缩放框架。依赖锁定4.6.2，classic UMD文件原样纳入src/vendor并与已安装依赖做字节校验，许可证纳入THIRD_PARTY_NOTICES.txt。

新增photo-zoom.js、photo-zoom.css及panzoom.min.js，经过tools/runtime-resources.mjs进入dist。按既有MV3 classic content script方式加载，i18n在前、Panzoom在增强脚本之前。不新增主机或downloads权限；仅使用X图片CDN公开CORS响应。

## 原图、边界及清理

仅对/status/数字/photo/1至4的原生modal内swipe-to-dismiss图片区域生效。限定HTTPS、pbs.twimg.com/media路径及图片格式，保留原始媒体ID和格式；排除头像、视频缩略图、非图片URL及外部主机。主原图返回404时有限尝试JPEG/PNG兼容格式，不把临时服务错误改成多次自动请求。

原图未能加载时保留预览图缩放，显示重试入口；只有确认获取原图Blob后才启用下载。下载使用Blob副本URL，并保留40秒，快速切图和关闭不会立即撤销下载地址。下载扩展名以实际响应MIME为准。

切图、关闭、SPA返回及扩展上下文失效时中止旧请求、移除缩放层、释放Panzoom和ResizeObserver并恢复原生图片。过期请求不能覆盖后续图片；预览尚无图片的加载空态不能抛错。平常时间线不请求原图；鼠标滚轮和拖动处理仅限图片画布。
