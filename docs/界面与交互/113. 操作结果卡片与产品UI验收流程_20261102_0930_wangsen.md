# 113. 操作结果卡片与产品 UI 验收流程

创建时间：2026-11-02 09:30，Asia/Shanghai。分支 feature/fan-review-flow；纳入尚未完成交付的 4.18.0，未提交、未发布。

## 产品行为

AI 审核、通过并入队、移除关注者及批量关系核验的终态结果统一使用窗口右下角非模态卡片。无背景遮罩与阴影，不抢焦点、不自动消失；每张卡片独立关闭。新结果排在最上方并展开，较早结果在下方保留标题与时间，点击标题可展开或折叠。排序不会因展开旧卡而改变。卡片随当前页面关闭而结束，不写入业务存储。

列表内保留进行中的进度以及暂停后的继续按钮；完成详情移出列表，不再弹出阻断式核验对话框。重新打开面板不重复弹出历史已完成批次；重复轮询相同结果去重。手动查看核验结果可以再次打开独立卡片。筛选下拉移除重复可见标题，保留可访问名称和说明。

## 复用与实现

采用 MIT 许可的 Vue Sonner 2.0.9，原生支持项目 Vue 3，运行依赖为空；npm 分发内容约 215 KB。复用通知事件分发、焦点与关闭生命周期，仅定制结果内容和用户要求的顶部新结果、书页标题排列，避免重写完整通知基础设施。官方项目：https://github.com/xiaoluoboding/vue-sonner 。

业务适配层只处理批次终态与轮询去重，结果文本使用 Vue 文本插值，保留 AI 标签与原始理由，不将原文作为 HTML。时间使用 Intl.DateTimeFormat；长内容在卡片内滚动，窄屏保持窗口边距。
