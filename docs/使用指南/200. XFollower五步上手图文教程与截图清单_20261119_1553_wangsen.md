# XFollower 五步上手图文教程

> 适用版本：XFollower **5.3.1+** · 对齐新版 11 项左侧导航、内置默认 X Grok、AgentRelay 本机免填 Token 接入与 7 天默认回关复核期限。 · 官网产品页：[https://goodexts.com/zh/xfollower](https://goodexts.com/zh/xfollower)

## 开始前 · 安装并确认 AI 引擎

从官方入口下载与你的 Chrome 兼容的 XFollower ZIP，解压到常驻文件夹。在 Chrome 地址栏输入 `chrome://extensions`，打开「开发者模式」，点「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的那一层。若浏览器支持拖入解压后的目录，也可按其界面操作；常规路径以「加载已解压的扩展程序」为准。在同一 Chrome 配置中登录 X，再打开 XFollower。 [Chrome 官方安装说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

在此次目标版本里，**内置 X Grok 默认用于打标与评论生成**。打开设置检查选中的引擎，先生成一条预览并核对原帖、语言和语气，再决定是否发送。首次用 X Grok 时，以 X 登录及该账号可用的 Grok 服务为前提。

进阶用户可安装并启动 **AgentRelay**，再在 XFollower 中选择 Codex、Antigravity 或 WorkBuddy。采用受支持版本且保留本机默认 Token 配置时，扩展自动连接本机服务，免手工粘贴 Token。浏览器提示允许访问本机服务时按界面确认。使用自定义配置、引擎未就绪或未连接时，先检查 AgentRelay 运行状态、对应引擎和会话。未就绪时可切回 X Grok。

左侧实际顺序按目标版本从上到下为「首页」总览 →「互关追踪」→「首页跟评」→「评论提取」→「粉丝跟进」→「通知监控」→「关注队列」→「回关监控」→「帖子追踪」→「X 榜单」→「知识库」。下列 5 步从「互关追踪」开始。

## 第 1 / 5 步 · 互关追踪：找一个同行锚点

1. 先定你准备长期输出的主题，例如英文独立开发或小团队的 WhatsApp 工作流。进入「互关追踪」，以推荐种子作为候选，或在 X 的实时搜索中组合主题和明确的交流意图。例如 `"indie hackers" "connect"`，再按「最新」查看。
2. 打开候选账号的 X 个人主页，检查近期原创和互动对象。挑一个与你受众接近、近期仍活跃的账号，复制显示名下方以 `@` 开头的用户名，或复制主页链接，填进锚点栏。配图中的 `@elonmusk` 只用来示范用户名的位置和格式。
3. 从一个锚点开始采集，先预览候选。保留有真实主题关联的人，再按需要放行到关注队列。互关追踪候选的基础权重是 80。

**完成信号**：互关追踪出现可审查的候选及来源。若没有结果，先确认账号和主题匹配，再用搜索换一个种子。

## 第 2 / 5 步 · 首页跟评与评论提取：持续发现新人

1. 在「首页跟评」先开采集与打标，检查它是否识别了明确邀请互关的帖子。挑与你主题相关的帖子，审核一条有上下文的评论后再决定发送。互动可以让别人发现你，首页跟评本身不等于关注发帖人。
2. 在首页跟评设置的「打标」区开启「评论取粉」（引导中写作「提取互关帖评论用户」）。符合条件的评论者可进入后续候选流程，基础权重 180。在「评论提取」核对记录。
3. 已有确定需要复盘的单帖时，定向提取该帖评论并逐个审查；普通评论提取基础权重 90。

**完成信号**：看见实际采集记录，且能区分首页互关帖和普通单帖两种来源。

## 第 3 / 5 步 · 粉丝跟进与通知监控：处理待回关

1. 在「粉丝跟进」同步关注与粉丝，打开「待回关」，确认对方已关注你且你尚未关注对方。先审查主页和近期内容，再放行合适的账号。
2. 「通知监控」用于发现新关注事件。收到记录后回到「粉丝跟进」核对关系；事件提示与关系核验是不同状态。
3. 确认的待回关候选使用最高基础权重 200。

**完成信号**：确认过的记录可以在关注队列按来源找到。若状态待核实，先查原记录。

## 第 4 / 5 步 · 关注队列：看清来源，再执行

| 优先顺序 | 进入来源 | 基础权重 |
| --- | --- | ---: |
| 1 | 确认待回关 | 200 |
| 2 | 首页互关帖评论者 | 180 |
| 3 | 普通评论提取 | 90 |
| 4 | 互关追踪 | 80 |

先核对来源、候选和执行设置，从少量人工确认开始。权重决定来源优先级，候选仍需满足筛选条件，并在执行前核实关系。遇到结果未知的操作，查看原任务和日志。在合适的原创帖子上，写一句有事实或经验的引用评价，例如补上一个可用的对比或指出你实测过的例外。先看原文、校对草稿，再决定是否公开发布。

**完成信号**：你能区分已执行、已跳过和待核实，并能在日志找到原因。

## 第 5 / 5 步 · 回关监控：设定 7 天复核期限

打开「回关监控」设置，确认最长等待回关期限。自 **5.3.1** 起，未保存过期限时默认 **7 天**；旧版已保存的期限仍会保留，可按需改为 7 天。先启用定时比对或手动查看一次逾期名单。把长期关注的作者、客户和合作对象加入保留名单；只对复核后确实仍未回关、你也不打算继续关注的账号决定是否清理。复核后回到第 1 步，按业务主题换种子或补充候选。

**完成信号**：界面显示所选期限，逾期记录能追溯实际关系，保留对象继续保留。

## 进阶内容工作台

- **帖子追踪**：观察原创帖的表现和新评论，挑出值得继续写的主题。
- **X 榜单**：观察同领域账号变化，结合原帖与读者互动分析原因。
- **知识库**：存可复用的写作经验、案例与复盘，下一次产出时引用。
