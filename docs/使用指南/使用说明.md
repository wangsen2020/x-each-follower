# XFollower 使用教程

这些教程按“安装 → 粉丝管理 → 互关追踪 → 评论追踪 → 自动化”的顺序编排。你可以先完成前三步建立自己的本地关系数据，再按需要使用评论追踪和定时功能。

## 教程目录

1. [安装扩展与第一次打开](01-安装与初次使用.md)
2. [粉丝管理：获取列表、筛选与回关](02-粉丝管理与回关.md)
3. [互关追踪：从锚点建立候选网络](03-互关追踪.md)
4. [评论追踪：从帖子收集评论用户](04-评论追踪.md)
5. [定时任务、近期帖子与执行日志](05-定时任务与日志.md)

## 三个模块怎么选

| 你要做的事 | 打开模块 |
| --- | --- |
| 看自己的粉丝、找待回关对象，核对自己关注了谁 | 粉丝管理 |
| 输入一个互关锚点，收集锚点的关注与粉丝账号，并查看这些人与自己的关系 | 互关追踪 |
| 从某条 X 帖子的评论者里找人，并保留每个用户来自哪些帖子 | 评论追踪 |

## 先了解这几件事

- 请在安装扩展的同一个 Chrome/Edge 用户配置中登录 X。扩展使用当前浏览器的 X 登录会话。
- 粉丝列表是逐步累积的本地档案；首次读取有单次上限，后续可以增量同步。列表数字反映本地已读数据，不保证是 X 上的实时全量数量。
- “互关追踪”分类看的是候选账号与你自己的关系；锚点只负责提供候选来源。“评论追踪”是独立模块，不会改名或并入互关追踪。
- 开启自动关注或点击“立即执行一次（看帖并关注）”会尝试真实关注 X 账号。先检查筛选门槛和候选，再开启或执行。
- 若 X 返回频率限制，扩展会记录失败/暂停状态。不要连续重复点击；稍后再查看状态或日志。
