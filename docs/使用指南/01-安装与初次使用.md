# 安装扩展与第一次打开

本教程适用于 Chrome 或 Edge。发行 ZIP 完整解压后加载产物目录；从源码安装则先运行 `npm ci`、`npm run build`、`npm run build:check`，再加载 `dist`。不要直接加载源码根目录。

## 1. 加载扩展

1. 下载或复制项目文件夹到本机。若下载的是压缩包，先完整解压。
2. 在地址栏打开 `chrome://extensions`；Edge 用户打开 `edge://extensions`。
3. 打开右上方的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择发行包的解压目录或源码构建生成的 `x-each-follower/dist`，确认所选目录里能直接看到 `manifest.json`。
5. 扩展卡片出现 **XFollower · 粉丝管理** 后，检查版本号。版本应与所下载发行包的 manifest 一致；本地候选版不等于已发行或商店已上线。

如果页面提示未启用安装功能，先确认开发者模式开关已打开，再重新加载扩展。不要选择 `docs` 子目录，也不要选择压缩包内部错误层级的空目录。

## 2. 登录 X 并打开管理面板

1. 在同一个浏览器配置里打开 `https://x.com` 并登录你打算管理的账号。
2. 点击 Chrome/Edge 工具栏中的 XFollower 扩展图标，打开粉丝管理面板。
3. 确认左侧导航有“粉丝管理”“互关追踪”“评论追踪”“关注队列”和“回关监测”。
4. 如果刚更新了源码，回到扩展管理页点击该扩展的刷新按钮，再重新打开面板。

打开面板后会先进入粉丝管理。图中圈出的是“已关注 / 待回关 / 未互关”筛选标签；教程截图来自实际扩展页面，账号列表已避开，计数也已遮蔽。

![粉丝管理面板的状态筛选位置](../images/panel-tutorial-home-annotated.png)

进入“关注队列”后会自动识别账号。若现有页面无法识别，扩展会自动打开后台 X 标签页完成初始化，并在完成后关闭；页面显示当前进度。自动处理失败后，点击“打开 X 完成登录”，登录后返回面板点击“重新识别账号”。登录必须在同一浏览器配置中完成。

## 3. 推荐的第一次使用顺序

1. 在“粉丝管理”点击“获取初始列表”，建立本地粉丝档案。
2. 浏览“待回关”和“未互关”列表，了解状态定义后再进行关注/取关操作。
3. 在“互关追踪”输入一个你认可的互关锚点，收集候选账号网络。
4. 打开“评论追踪”，在 X 帖子操作栏点击评论追踪图标，建立评论来源记录。
5. 进入“关注队列”，等待账号自动识别，选择来源并确认数据归属，点击“确认来源并接入队列”。首次导入较多候选时请等待接入提示完成。
6. 在队列齿轮设置中检查筛选条件、周期和额度，再按需打开顶栏“定时自动调度”。默认不会自动关注或发布；启用后会实际执行账号操作。

## 4. 更新后版本没变化

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 找到 XFollower，点击卡片上的刷新图标。
3. 关闭旧的面板标签，再从工具栏图标重新打开。
4. 查看面板标题附近的版本号。若仍是旧版本，检查“加载已解压的扩展程序”指向的路径是否为本次重新构建的 `dist` 或发行包解压目录。更换加载路径可能改变扩展 ID；保留旧安装和备份，确认历史数据恢复后再处理旧版本。


## 5. 商店升级与移除重装的区别

商店升级后，刷新或重新打开 X 页面会加载新脚本；关注队列也能在识别失败时自动通过临时页面初始化。通常无需移除扩展。

移除扩展会清除扩展自身数据。重新安装后，需要重新识别账号、确认来源；如果 X 站点上仍保存原模块数据，可以重新导入候选，但不要将其理解为完整队列历史和设置均会恢复。网络异常或未登录时，请按页面引导处理。
