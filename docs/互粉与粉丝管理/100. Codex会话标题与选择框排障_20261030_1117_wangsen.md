# Codex 会话标题与选择框排障

本轮修复覆盖 XFollower 与 AgentRelay。隔离分支分别为 feature/codex-session-fix、feature/codex-session-titles，基于已核实的 develop 创建，原工作区未修改。

## 原因与修复

AgentRelay 在缺少 thread.name 时把 thread.preview 正文当标题。改为只读 Codex session_index.jsonl 的 thread_name，优先最新记录，再使用官方 name 或明确创建的本地名称；缺少标题时显示未命名会话与 ID，不使用正文。坏行不影响其他会话。查询不写 Codex 数据。

扩展各入口复用同一会话读取器，选项清理控制字符与换行、限制显示长度。完整标题保留在 title 元数据，系统设置及关注队列可悬停查看；选择与持久化继续使用原 ID。系统设置旧配置显示也经过规范化。颜色明确匹配浅色背景，状态长文本允许换行。

复用已有 Vue PanelSelect 和原生 select，无新增 UI 依赖。Codex 官方参考：https://learn.chatgpt.com/docs/app-server 。本机实际存在会话名称索引，已只读验证。
