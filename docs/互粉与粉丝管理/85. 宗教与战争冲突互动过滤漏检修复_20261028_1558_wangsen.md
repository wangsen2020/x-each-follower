# 宗教与战争冲突互动过滤漏检修复

## 背景和根因

2026-10-28 的引用任务采集到阿拉伯文原帖“يا الله لك الحمد”和作者近期的战况信息。宗教互动词表遗漏了真主的阿拉伯文与中文表达，军事词表缺乏相关阿拉伯文词汇，因而关注、选帖与发布检查均未拦截。已发布记录同时保存原文与中文版本，不能据此推断翻译发生位置。

## 修改

- 在独立于风险标签的互动偏好中过滤真主及部分多语言宗教、战争冲突词汇，对阿拉伯文的组合符号做归一化处理；检查全部传入的近期帖子。
- 待回关放行不能绕过互动偏好；读取完整原帖后重新检查，发布前再次检查原帖、账号上下文和生成内容，覆盖恢复草稿与不同发布形式。
- 保留既有记录，不改动真实账号或历史发布。

## 验证和限制

- 对该事件的阿拉伯文、中文原帖及战争表达，测试关注筛选、引用生成前与发布前拦截；验证待回关放行和第十条之后的帖子。
- 全量自动化测试 1285 项通过，源码检查与构建通过。未使用真实账号执行关注或发布，也未对运行中扩展执行端到端写操作。
- 词表不是可靠的全语言语义审核：同义表达、隐喻、图片、音视频和未知语言仍可能漏检；不得将本次结果描述为所有语言均有保障。需增加经验证的跨语言语义审查及不可判断时阻止自动操作，才能向该目标继续推进。
