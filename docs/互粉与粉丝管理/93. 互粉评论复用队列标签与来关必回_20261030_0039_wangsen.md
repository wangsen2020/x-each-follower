# 互粉评论复用关注队列标签与来关必回

创建时间：2026-10-30 00:39（北京时间）；作者：wangsen。

本轮为已跑通互粉评论的新一轮功能补充，在既有Git Flow分支feature/mutual-comments继续。版本4.6.0，新增评论内容配置，未提交、推送或发行。

## 产品与复用

互粉评论设置的评论分组新增“来关必回”和“追加随机标签”。与关注队列使用相同推荐标签、清洗、候选选择、语言筛选、随机抽取、加权长度和同义去重实现；不另写一套内容规则。

来关必回直接调用composeQueueFollowBack。中文文案“关注我，必回关！🤝”，英语、西班牙语、葡萄牙语和越南语沿用队列已有文案；正文已有同义邀请不重复追加。开关默认关闭，独立于关注队列保存。

随机标签直接调用normalizeQuoteTags、validateQuoteTags、appendQuoteTags。最多选择10个候选，每条按评论语言随机选最多2个；支持最多50个自定义标签、添加及删除。空间不足时减少标签，不截断正文。新增CommentTagsSettings组件复用队列标签数据与函数，提供统一的推荐/自定义选项和预览。

## 持久化与恢复

每条评论发起生成前冻结标签候选及来关必回开关。AI原文解析后，先追加邀请，再在剩余空间内追加随机标签；将原始评论、语言、配置快照、最终评论一并入库后才调用现有发布器。恢复任务使用原配置；已完成草稿沿用原来的最终文字，不重新抽取。

来关必回无法在280加权字符内容纳时保留原文草稿并记录问题，不悄悄删掉用户要求的邀请或截断正文，也不自动发布该草稿。其他可执行帖子继续处理。

设置包含数组，保存后的回读校验改为比较序列化内容，避免Dexie返回新数组引用被误判为未保存。账号开关、原有调度及Bot绑定不变。详情显示标签与来关必回快照和最终评论。

## 验收

1366项单测、55项构建测试通过；163模块语法及199个JS/Vue文件调用契约检查通过。新增回归验证：最终发布文字包含邀请与两个标签；配置数组保存后正确回读；等待中的Bot任务恢复沿用原标签/开关；正文过长保留草稿且不发布。

在隔离浏览器页面使用实际Vue组件验收10个候选上限、自定义标签添加、保存成功弹窗、关闭重新打开后配置恢复。仅自建验收标签页被关闭，没有触发真实X发布或改变用户标签配置。真实扩展在已有采集/评论任务空闲后加载新构建，新增开关默认关闭，由用户保存选择后对新生成评论生效。

## 真实标签评论验收与4.6.1修复

用户明确要求开启两个开关、复制关注队列标签并实测发一条。读取当前账号及队列配置后，已保存来关必回、随机标签为开启；完整复制队列10个候选：互关必回、FollowBack、FollowForFollow、MutualFollow、F4F、LetsConnect、互关互赞、蓝V互关、VerifiedFollowBack、BlueCheckCommunity；无自定义标签。

实际评论原帖为dierjie2的2115815573456408729，发布结果[2115847138538344499](https://x.com/WatsonTaylor23/status/2115847138538344499)。完整结果包含“关注我，必回关！🤝”和“#互关互赞 #蓝V互关”。在独立临时窗口的账号回复页可见；再通过既有network client查询TweetDetail，HTTP200返回authorId1485853007346827264、in_reply_to_status_id_str2115815573456408729与完整文本，包含😄和🤝，逐项匹配。临时核验窗口已关闭，未重复发送。
