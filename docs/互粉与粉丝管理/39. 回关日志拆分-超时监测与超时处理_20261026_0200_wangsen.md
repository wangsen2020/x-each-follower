# 回关日志分类与重复结果展示修复

## 产品目标
关系比对日志频繁刷新，容易淹没取关和提醒记录。拆成三个互斥分类，使“发现超时”和“处理超时”分开阅读。

## 分类与交互
- 超时监测：关系比对、账号状态更新、定时或手动检测、超时判定及通用核验。
- 私信提醒：自动和手动提醒及开始、跳过、成功、失败、待确认记录。
- 取消关注：自动和手动取关及结果，默认打开此分类。跳过或待确认不代表已取关。
- 标题、空状态、条数、分页随分类变化；切换分类返回第一页。
- 清空按钮明确标注“清空全部分类”，确认文案同样说明范围；不进行隐式清理。

## 实现边界
复用现有 execution-log-store、查询游标及旧后台兼容读取，不引入新存储或重复日志。按 source、origin 和历史 unfollowedHandles 字段分类，不根据成功状态推断动作。后台先分类再分页；旧后台不识别分类参数时，读取该范围全部分页后分类和分页，避免第一页缺记录被误判为空。
