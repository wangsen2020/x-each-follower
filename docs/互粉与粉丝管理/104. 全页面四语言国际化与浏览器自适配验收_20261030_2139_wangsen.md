# 全页面四语言国际化与浏览器自适配验收

本轮接续首批 AI 设置国际化，扩展到九个业务页面、系统设置、日志及详情弹窗、两份 Grok 教程、安全验证提醒和 X 页面注入按钮。开发位于隔离 worktree xfollower-i18n、feature/four-language-i18n；开发版本 4.10.0，尚未提交、合并或发布。

## 语言与实现

只依据浏览器 UI 语言选择：英语 en、简体中文 zh-CN、巴西葡语 pt-BR、拉美西语 es-419。不读取旧手动语言偏好；其他语言回退英语，同语种地区变体映射到支持的译文。Chrome 原生目录为 es、pt_PT、zh_TW 提供相应别名，避免经典 content script 与面板选择不一致。

复用 i18next 管理 Vue/面板译文，Chrome i18n 管理 manifest 和经典 content script。tools/build-i18n-catalogs.mjs 从四语言词典生成原生目录和注入适配器，构建时校验占位符与资源。经典脚本只定位显式标记的扩展 DOM，不扫描翻译 X 原帖。并行构建使用原子写入避免读到半文件。

翻译限于展示层：底层状态、存储字段、业务判断、AI 提示词和教程提示词正文保持原样；作者名称、简介、帖子、生成内容、会话名称及实际发帖标签不翻译。对动态统计和相邻占位符采用显式参数，避免误拆状态或翻译用户原文。扩展失效时卸载观察器，已翻译徽章标题直接比较，防止重复 DOM 更新。

## 验收边界

运行的是本机真实 Chrome 的隔离无头扩展实例；并非现有登录账号的线上业务验收。用户正在使用的主 worktree、共享 dist 与登录 profile 未覆盖或重载。业务/平台/后台目录没有本轮改动；面板 AI prompt 变量的前后比较记录在 artifacts/i18n/prompt-invariance.json。词库一致性和展示回归不等于每条长日志均经母语编辑逐句审校。

## 复现

在该 worktree 执行 npm run build，再执行 node tools/i18n-real-acceptance.mjs；可追加 en-US、zh-CN、pt-BR 或 es-419 限定语言。测试数据只写入测试自己创建的临时 Chrome profile。构建产物在该 worktree 的 dist/，未经用户授权不替换正在使用的版本。

最终结果：四语言报告均为零运行错误，每语言 37 个页面/弹窗快照及 1 张 X 注入截图，共 152 张。四语言十四个弹窗均实际打开，分页保存值与重开值均为 50；原帖保持原文。非中文界面检测到的汉字仅为测试作者名称、简介、AI 草稿及保留的实际发布标签。西语窄屏设置导航补充显式可换行标签后已重新截图检查；原文保护与 UI 交互 fixture 再次通过。
