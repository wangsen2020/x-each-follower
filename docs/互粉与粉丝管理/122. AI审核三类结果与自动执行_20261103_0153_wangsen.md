# AI 审核三类结果与自动执行

本轮按用户 2026-11-03 的明确纠正，调整粉丝审核语义。继续既有 feature/fan-review-flow，目标 4.25.0；不提交、推送或发行。

| AI 结论 | 产品状态 | 后续动作 |
| --- | --- | --- |
| 通过 | 待回关 | 保留粉丝管理渠道并加入关注队列 |
| 不通过 | 移除执行中或已移除 | 通过现有受保护执行器移除关注者，确认后更新关系 |
| 资料不足 | 待核实 | 补充资料和最多 10 条帖子，再审核；一轮后仍不足保留待核实，不自动无限循环 |

请求、格式、身份及移除执行异常独立显示“异常”，不算业务不通过。AI 不通过和实际移除成功分开记录；未知外部提交不重复发送。既有历史 review 建议不追溯成移除指令，新审核批次保存三类策略版本；旧在途结果保持原处理语义。

复用现有 JSON 解析、Dexie 数据事务、持久移除意图和核验采集流程。人工主动再次核验允许启动新的补采复审轮次。结果浮窗按通过、不通过、资料不足分类统计，技术异常和跳过单列。

验收覆盖自动初审、手动 AI 审核、无效返回不删除、移除回执未知不重发、资料不足归类及重跑、旧批次兼容；执行全量单测、构建和实际 UI 检查。
