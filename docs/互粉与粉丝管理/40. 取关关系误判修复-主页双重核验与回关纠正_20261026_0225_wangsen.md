## 判定与执行
- 粉丝名单或正向关系证据不能被旧的负向值覆盖；登记关注不再凭空制造负向关系。
- 复用项目现有 profile-access、network-client、记录服务；新增最小业务校验层，不新增第三方基础设施。
- 每次候选核验打开自建非激活主页，核对登录账号、目标 handle 和精确 User ID 按钮，排除帖子、推荐卡。
- 实时接口与主页 following 不一致即未知；关注了你或回关为正向证据，禁止取关。没有徽标不能单独证明未关注，必须接口明确 followedBy=false、页面就绪且正在关注。
- 自动及手动取关统一通过目标主页按钮和确认弹窗，确认前再次实时核验。无直接取关接口降级。页面点击本身仍会由 X 发出正常网络请求。
- 已互关更新本地并出队；回关状态执行一次主页回关，确认双方互关再回写；结果不明保留 pending，禁止重复动作。
- 自动流程在动作前和最终确认前重新检查自动开关、绑定账号、窗口、白名单与豁免；手动流程复用主页身份与关系门禁，不依赖自动开关。
