# 各栏目表格滚动与抽屉提示统一修复

用户要求顶部标题、统计、筛选与分页固定，仅表格内容沿Y轴滚动；同时全局处理抽屉关闭后tips因焦点恢复而重现。

## 分支与实施

从已与远程同步的develop执行git flow feature start panel-table-scroll，实际开发分支feature/panel-table-scroll。版本4.6.3为已发布4.6.2后的样式与交互修复，未提交、推送或发行。未改动用户定时、Bot、标签和数据。

新增table-scroll.css统一约束面板和内部容器高度。互粉评论由整页滚动改为表格滚动；关注队列约束followQueueContent、内部fq-panel-root及fq-list-section三层容器，避免表格撑开页面；知识库固定到主网格第2列第2行，列表占剩余高度。帖子追踪、X榜单和其他已有内部滚动栏目统一检查，表头吸顶；手机宽度主布局仍有界限，列表保留剩余空间。

提示层记录刚点击激活的提示控件，原控件恢复焦点时不重新显示；抽屉关闭后移出再进入可重新显示。识别弹窗时排除hidden、aria-hidden与inert的常驻抽屉，避免错误地永久抑制提示。统一作用于data-panel-tip及info-tip提示，不逐栏目另写逻辑。

## 初始化与帖子追踪顶栏精简补充

已接入且绑定账号与当前识别账号一致时，关注队列入口直接渲染队列，不再显示确认来源、归属确认和初始化说明。首次接入或账号不匹配时仍保留原确认流程。账号图标改为可点击的账号与来源管理入口，明确打开原生抽屉；查看和关闭不执行激活或同步，保存来源才走既有后端账号核验及来源更新。已有已确认账号不再重复要求归属确认，首次仍严格检查。后台定时syncCandidates继续同步已启用来源的本地候选，原有各来源采集与队列执行调度开关不变。

帖子追踪将视图标签、账号/监控数量/倒计时、刷新及设置按钮放入同一个post-head。实机高度30px，标签及操作区均为30px，状态行20px居中，移除额外独立标签行；窄屏允许按空间换行。

隔离验收未确认时激活请求为0，确认后仅发出1次激活并立即移除初始化区；来源抽屉查看关闭没有额外请求。真实已接入账号setup false、说明段落0、header top21；来源管理关闭后tooltip false。1370项单测、55项构建测试和源码检查通过。
