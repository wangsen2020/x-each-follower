# 统一操作栏与待核实批量处理

## 范围与版本

- 开发分支：feature/release-readme-workflow；开发版本 3.3.1，未发行。
- 粉丝跟进、互关追踪、评论追踪、帖子追踪、榜单、回关监控、知识库的同类页头操作统一使用图标与悬停或键盘焦点提示。
- 关注队列新增待核实任务的批量核对、排除和删除，保留原有单项操作。

## 共用组件

- PanelIconButton.vue 与原生 DOM 的 panel-icon-button.js 共用 Lucide 图标数据和 PANEL_ICON_ATTRIBUTES，固定 16px 图形及一致描边。
- PanelActionBar.vue 与原生 DOM 使用 panel-action-bar，共用 30px 按钮和 10px 间隔；窄屏允许换行。
- InfoTipLayer.vue 同时识别问号 data-tip 与操作控件 data-panel-tip，统一处理悬停、键盘焦点和视口内定位。
- 原按钮 ID 与事件入口保留。粉丝扫描、互关更新及 Grok 分析的动态说明改写到提示属性，不再替换按钮内容破坏 SVG。
- 移除互关旧 ID 对图标按钮宽度和内边距的覆盖；图标库许可证包含在 THIRD_PARTY_NOTICES.txt。

## 批量操作边界

- 只在待核实筛选下提供批量入口，只处理当前页已勾选且仍为 uncertain 的任务。该筛选切换条件、页码或每页条数时清空选择；其他筛选的跨页选择行为保持原样。
- 三种操作开始前均提示数量与影响并确认。核对读取最新关系；已关注则同步状态，未关注则恢复待关注，因此开启调度时后续可能执行。
- 排除仅停止队列后续执行；删除复用已有删除接口及旧来源防重入规则，不在 X 上取关。
- 逐项复用 followQueueVerify 与 followQueueDelete。保留后台账号绑定、任务状态和执行检查，不增加绕过校验的批量后台接口。
- 运行时锁定筛选、选择、分页及其他操作。显示已处理数、成功数、失败数和逐项失败原因；成功项移出选择，失败和未执行项保留供重试。
- 停止后续不打断当前请求，当前项返回后停止下一项。关闭页面或切换执行账号也不再继续发送下一项；已发送请求可能完成，不宣称撤回。
- 结果不伪装成全部成功，详情中保留失败账号与原因。最终刷新分页数据，避免删除后页码失效。

## 验证

- npm test：当前工作区 1063 项通过，包括批量确认取消、顺序执行、部分失败保留选择、删除与排除复用单项命令、停止后续处理。
- npm run check：源码语法与浏览器调用契约通过。
- npm run test:build：54 项通过；主工作区 dist 已重新构建并校验。
- CDP 连接现有 Chrome，在独立测试标签渲染真实 Vue 页面组件，以模拟后端隔离用户数据。
- 7 个页面分别在 1400px 和 375px 下实测：图标按钮 30×30px，水平间隔 10px，提示位于视口内。
- 待核实批量工具栏在两种宽度下均可访问；受控核对 3 项得到成功 2 项、失败 1 项，失败项保留选择，随后只向该失败项发送确认删除。
- 上述浏览器验收使用模拟数据，未对真实 X 账号执行关系核对、排除、删除或关注；当前运行中的扩展未为本轮测试重载。

## 同一迭代补充-队列行内操作

关注队列每行的核对关系、排除、溯源详情和删除已复用 panelIconButton 与 panel-action-bar，统一为 30×30px 图标和 10px 间隔。同一操作栏内的评价核对、发布和重试入口也使用图标及对应提示。原确认流程、忙碌状态与执行中禁止删除的规则保留。

1400px 与 375px 的受控组件预览均验证四个图标保持单行，间隔为 10px；悬停及键盘焦点提示完整位于视口内。相关 44 项面板测试及源码检查通过，dist 已重新构建并校验。
