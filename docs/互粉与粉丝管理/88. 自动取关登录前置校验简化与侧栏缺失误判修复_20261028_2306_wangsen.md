# 自动取关登录前置校验简化与侧栏缺失误判修复

## 现场与范围

2026-10-28 22:57:01，@haidaulau 在实时核验取关条件阶段失败，代码 X_PROFILE_OWNER_MISMATCH，显示“绑定账号未就绪”；21:56:44 的 @F1uxoo 同类。原始记录没有保存实际读到的账号，不能断言历史现场确实发生了账号切换。

代码存在确定的误分类：侧栏链接未出现时，undefined 与绑定账号比较不等，直接报登录账号不一致。此外自动取关每轮查询绑定账号自身资料，并在目标请求前后反复扫描侧栏，引入与目标操作无关的失败点。

## 处理

按用户要求简化自动取关及其回关修复流程：删除 adapter 的每轮绑定账号资料查询，删除重复侧栏扫描，仅选择现有可用 X 请求标签；优先完整加载页面，忽略已丢弃标签。没有 X 标签明确报告缺少请求页面，不再假称账号不匹配。

实际目标主页上，侧栏缺失不再视作账号切换；明确出现不同账号仍阻止操作。不存在账号的页面核验同样区分缺失与明确不一致。目标 User ID、目标主页身份、API/DOM 双重关系、互关保护、白名单、额度与提交检查点均保留；401/403/429 等接口错误仍按原规则暂停。没有长期缓存账号密码或会话凭证。私信与其他业务流程未在本次改变。
