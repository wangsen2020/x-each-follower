# 取关日志账号明细与分类筛选

## 问题

回关监控日志混合自动私信、本地比对和取关事件。自动取关成功详情有 handle，但轮次汇总未写入 unfollowedHandles，页面已有的账号列表区域无法展示；手动单个和批量取关也缺少对应账号日志。

## 修改

- 新增“全部 / 取关”日志筛选，不改变历史记录与原有清空范围；取关筛选下禁用清空，避免误清全部回关监控日志。
- 自动取关在关系复查、回写与出队完成后记录成功账号，成功详情及本轮汇总写入 unfollowedHandles；失败与不确定结果不进入成功列表。本轮结束同步更正提交状态，避免成功汇总沿用请求待确认状态。
- 手动和批量取关在本地保存后追加独立来源日志与账号列表；批量每次成功即保存并写日志，避免中途停止漏记。
- 旧日志仅在明确成功、具有 handle 且提交状态为已确认取关并回写本地时展示该账号；不猜测旧汇总中缺失的完整名单。

## 复用及数据边界

复用 execution-log-store 的范围索引、游标分页和写入备份，无新增依赖或数据库结构。取关筛选在同一个只读事务内扫描范围成员，读取日志判定来源并计算筛选后的总数与游标，不做页内过滤；不改变写入串行边界。为兼容正在运行的旧后台，前端识别缺少 kind 确认的响应，遍历已有分页后筛选；兼容路径只在用户读取该分类时运行，读量与该时间范围日志总数相关。
