# 取关日志关键诊断信息直显

创建时间：2026-10-26 10:24；作者：wangsen；版本：2.16.9。

归档复核：2026-10-26 11:41。同一需求的说明与验收补充，保留第 43 号。

## 问题与目标

身份核验失败日志的摘要没有账号，目标账号藏在折叠详情里，部分记录缺少账号 ID、具体失败原因。排查需要再查用户记录，且用户容易把检查目标误认为已取关账号。本轮独立补齐写入与展示，不修改关注关系和自动取关规则。

## 实施

- 复用既有 Vue 日志卡片、审计上下文和日志分页；不增加数据库查询，不引入新依赖。
- `followback-audit.js` 在输出事件时从当前目标上下文生成顶层 handle 和独立 target，保存账号、昵称与 ID；日志自身 ID 不作用户 ID。
- 自动取关在每个目标核验前刷新目标上下文，记录操作前关系与未操作状态；失败摘要包含账号，详情保留原始错误原因。成功确认后记录操作后关注关系和已核验状态。
- `followback-log.js` 统一提取新结构及历史详情里的信息，历史缺失的 ID 显示“未记录”，不查询数据库补造历史事实。
- 日志卡片在折叠详情外显示目标主页链接、账号 ID、绑定账号、阶段、操作前后关系、执行状态、页面操作、操作或 HTTP 状态、错误代码、原因与完整轮次。存在的字段才显示；目标尚未选择与历史未记录区别显示。
- “已取关账号”继续沿用明确成功证据判断，不能用当前目标代替成功列表。没有取关结果的失败和跳过日志不会新增已取关标识。
