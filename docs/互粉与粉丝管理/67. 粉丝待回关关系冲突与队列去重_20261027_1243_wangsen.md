# 粉丝待回关关系冲突与队列去重

## 现场与原因

3.3.6 实机只读检查中，待回关队列记录与本地关系汇总存在大量冲突；历史关注成功不能证明当前 X 关系。关注扫描使用包含旧的否定关系的索引，可能阻止新鲜关注列表更新；记录级增量保存不会删除从数组移除的旧行。已核验跳过任务也可能被放行同步反复重排。

## 修复

- 本轮关注列表结果直接作为新鲜证据更新粉丝档案；只将本轮实际扫描结果用于队列关系对账。
- 已确认关注的粉丝队列记录保留并更新为已关注，通过增量写入持久化，而非仅从内存数组删除。
- 待回关放行仅允许未核验的历史跳过任务恢复一次；已核验跳过任务保留结果。执行前仍核验实时关系与身份。
- 旧冲突不按历史成功批量覆盖，需后续扫描实际确认；扫描覆盖不完整时不能保证所有历史数据已经准确。

## 验证

定向单测及完整测试通过；构建及产物检查通过。已在当前登录扩展重载 3.3.7，面板可打开；重载后待回关仍显示 389，历史冲突仍在。尚未触发实机扫描，不能声称历史数据已校正。
