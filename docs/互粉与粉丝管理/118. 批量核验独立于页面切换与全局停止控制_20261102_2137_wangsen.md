# 批量核验独立于页面切换与全局停止控制

创建时间：2026-11-02 21:37。分支：feature/fan-review-flow。版本：4.22.1。

## 需求与版本确认

用户要求当前任务结束后切换修复版、刷新并验证补采队列真实数据，同时纠正切换分类会取消批量核验的交互。实查在用版本已经是 4.22.0，用户明确选择保留较新功能并更新到 4.22.1，不回退到 4.21.1。

## 行为

核验启动时固定当前所选账号。切换粉丝分类、搜索、审核结果、每页数量、翻页、默认分页设置与其他模块仅更新视图、清空未提交选择，不取消已启动批次。显式停止完成当前项后暂停，保留检查点与结果，可以继续剩余账号。账号变化、登录异常、限流等安全暂停规则保留。

## 实施

- changeFollowerContext 不再发送 followQueueFanBatchCancel，也不清除任务轮询和待返回的启动请求。任务命令与状态轮询使用独立序号，防止切换视图丢弃已经启动的任务回执或停止进度刷新。
- 后台忽略携带视图变化 kind 的旧版取消消息，避免其他旧面板误取消任务；显式停止与原有管理取消能力仍独立。
- 将核验进度、停止、继续和结果图标移到 PanelHeader，切换其他模块仍可操作。调整空标题栏隐藏规则，任务结束后不留下空白行。
- 复用统一图标、键盘与悬停提示，更新四语言说明。
