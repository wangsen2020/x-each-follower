# 粉丝移除规则可选开关

## 规则

4.31.0 新增账号级 removalRules.blockSuggestive 与 blockEmpty，均默认 false。旧用户缺少字段时按关闭读取，不需要直接修改用户数据库。

- 拦截擦边控制粉丝关键词、AI 提示词和结果处理，仅有擦边依据时关闭即不移除；其他独立拒绝原因不被放行。
- 拦截空号只针对核实后简介及帖子同时缺失。开启则进入移除队列，关闭则放行入关注队列；超时、限流、私密或采集失败不是空号证据。
- 已排队但未执行的旧移除结论，如仅依赖当前关闭的规则，取消任务并回到审核。已完成的移除历史保留。
- 设置位于粉丝初审与 AI 打标的移除规则分组，按账号保存，队列设置保存不覆盖这两个字段。复用现有 Vue 控件、设置读写和 Dexie 移除队列，无新通用调度器。

## 验收

关键词、AI、空号放行及待核实结束路径、旧队列取消、默认值与独立合并有回归测试。隔离 UI 验证默认均关闭、分别启用后保存重开、键盘空格切换；检查 1280、390、640 宽度及英文。截图 C:/jtmp/xf-removal-rules。完整单测 1927 项、构建回归 58 项通过；205 个模块语法和 248 个文件浏览器契约检查通过。21:40 在任务空闲时加载 4.31.0，manifest/background 一致，17 项原有 alarms 保留。真实设置读取两个值均 false，桌面 1280 与窄窗 390 截图已查看，未改动用户既有设置。实机只读报告 live-acceptance.json。未手动关注或移除账号，未提交、推送、发行。

补充边界：已存在但无文字的帖子不算空号；手动确认移除不受自动内容拦截开关影响。开关保存及重开在隔离设置夹具中验证，实机确认版本、默认值、布局及原调度保留，不以开关验收触发真实 X 移除。
