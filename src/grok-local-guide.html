XFOLLOWER / GROK BOT

把你自己的 Bot，
接入 XFollower。

在本机运行 Grok Bridge，把已登录的 Grok Bot 连接到插件。完成一次配置与生成测试，之后在创作配置中选择具体 Bot。

XFollower→本机 Grok Bridge→已登录的 Grok Bot→回复返回插件
  • 准备 Windows x64 电脑、已安装并登录的 Grok Bot 桌面端，以及当前 XFollower 扩展。
  • 先在 Grok Bot 中创建或选定一个能正常对话的 Bot。实际可用额度以你的 Grok Bot 账号为准。
  • Grok Bridge 是第三方开源工具，复用本机桌面端会话。使用时，电脑、Grok Bot 和 Bridge 都需要保持运行。

这条本地通道无需 Cloudflare 账号、Worker 或 Webhook 签名密钥。需要网页自动化方案时，参见Webhook 接入教程。

01 / 下载与运行

完整解压，直接运行

  1. 下载 Grok Bridge 0.7.0 · Windows x64 完整 ZIP。此版本已经包含运行 Bot 所需的组件，无需安装 Node.js 或 grok-bot-cli。先打开 Grok Bot 桌面端并登录。
  2. 若从 0.7.0 正式发行页下载，展开 Assets，选择 grok-bridge-0.7.0-win-x64.zip。不要选择「Source code」。需要校验时，同页下载 SHA256SUMS.txt。
  3. 把 ZIP 完整解压到固定、可写的文件夹，例如用户目录下的 GrokBridge。保留下面两个 EXE 和三个 DLL，双击 grok-bridge.exe。不要直接在压缩包内运行，也不要只拷走桌面 EXE。
grok-bridge-0.7.0-win-x64/
  grok-bridge.exe                     ← 双击这个桌面程序
  grok-bridge-service.exe             ← 自动启动的配套服务
  Microsoft.Web.WebView2.Core.dll
  Microsoft.Web.WebView2.WinForms.dll
  WebView2Loader.dll
  config.example.json
  README.txt
  1. 首次启动会自动生成 config.json 与任务目录，桌面外壳自动启动本地服务。首页显示「运行中」后，记下「访问凭证」处的端口，Token 保持隐藏。
桌面窗口依赖 WebView2 Runtime；缺失时程序会提示并提供浏览器窗口回退。升级前先退出旧 Bridge，再替换完整程序文件，保留 config.json、jobs、logs 与登录数据。旧配置里的端口、Token 和性能参数会继续使用，不会被新默认值覆盖。

02 / 允许扩展连接

只允许你的扩展访问

  1. 在 XFollower 打开「系统设置 → Grok Bot → 授权」。点击「复制扩展地址」。下方也能复制当前扩展地址。
  2. 在 Bridge 打开「设置」，点击「打开配置文件夹」，用文本编辑器打开 config.json。
  3. 找到 allowedOrigins 数组，加入刚复制的扩展地址。已有其他地址时，在数组内追加并用英文逗号分隔。保留其他配置、端口和原 Token。
  4. 保存文件，回 Bridge「首页」点击「重启服务」。等待「运行中」恢复后继续；正在生成时，等任务结束再重启。

只修改下面这一项；这是一段配置片段，不能覆盖整个 config.json：

地址必须与当前扩展一致。切换浏览器、开发版或商店版可能改变扩展 ID，需要追加新的地址。不要填 * 或网页的 X.com 地址。JSON 数组与字段之间需保留正确的英文逗号。


03 / 插件连接
填写端口，读取 Bot 列表
  1. 回到 XFollower「系统设置 → Grok Bot」，依次完成「下载」「授权」，进入「连接」。
  2. 填写 Bridge 首页显示的端口；默认是 8787，改过端口就填实际值。
  3. 在 Bridge 首页的「访问凭证」点击「复制」，粘贴到插件「连接 Token」。这不是 Grok 密码，也不是 Webhook 签名密钥。
  4. 点击「读取 Bot 列表」。浏览器提示访问本机服务时，允许本次连接。
  5. 在「测试 Bot」中选择一个具体 Bot，再点击「下一步：测试」。列表来自当前 Grok Bot 登录账号。
读取列表成功说明连接可用，尚不代表生成成功。若列表为空，先去 Grok Bot 桌面端确认账号下有可对话的 Bot。


04 / 验证完整回复
测试通过，才能启用
  1. 核对页面上的端口和测试 Bot，点击「测试并启用」。这会向所选 Bot 发送一条实际测试消息，消耗对应账号用量。
  2. 等待完整回复。任务已接收或正在生成时，不重复点击，不把等待误判为失败。
  3. 出现「测试通过，配置已保存」后，连接才可启用。端口、Token 与连接信息保存在本机扩展数据库；重新打开设置会恢复。
  4. 测试失败时按页面提示修正，完成后重新测试。不要仅凭 Bridge 显示运行中就认为插件接入完成。


05 / 开始创作
在使用入口选择 Grok Bot
  1. 回到粉丝跟进的创作配置，找到 AI 生成相关设置，选择「Grok Bot」。
  2. 在创作配置中选择本次生成使用的具体 Bot。系统设置中的 Bot 用于测试连接；同一连接的测试不会替你切换创作 Bot。
  3. 按需要设置发布方式、参与概率等，再保存创作配置。启用连接不等于自动开启发布。
首次选择尚未配置的 Grok Bot 时，插件会打开接入设置。回到使用入口后再确认当前选择，避免配置完成却仍使用原通道。


日常使用与升级
  • 关闭设置：已验证的连接保留。连接 Token 不进入业务数据备份，换电脑或重装扩展需要重新连接。
  • 关闭窗口：Bridge 当前版本关闭主窗口可留在托盘。以首页「运行中」与托盘状态为准；「退出软件」会停止本地服务。
  • 任务中断：服务保留任务，插件通过原任务查询已发送的回复。遇到「待确认」先核对原任务与 Bot 会话，避免新发一遍造成重复。
  • 升级 Bridge：等生成结束后退出旧版，再按新 Release 说明替换程序文件。保留 config.json、jobs/ 与其他本地数据目录；新版 ZIP 的 EXE 与 DLL 要一同更新。
  • 保护凭证：不要分享 config.json、Token 或登录数据。截图时隐藏 Token，分享排错信息前也应遮盖私密路径与消息正文。
