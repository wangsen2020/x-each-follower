XFOLLOWER / AI ENGINES

连接你的 AI 引擎。

通过本机 AgentRelay，将 Grok Bot、Codex 和 Antigravity 接入 XFollower。共用一份连接，各自保存会话，业务入口独立选择。

XFollower→AgentRelay→Grok Bot / Codex / Antigravity

本机通道无需 Cloudflare。需要云端回调时，使用云端事件 Cloud Event 教程；当前云端事件提供方为 Grok Automation Task。

01 / 安装与运行

先启动服务和所用客户端

  1. 从 AgentRelay 正式发行页选择 Windows 安装包或便携包，阅读对应发行说明。不要下载 Source code 作为运行程序。
  2. 安装或完整解压后运行 AgentRelay。Grok Bot、Antigravity 客户端须安装并登录；Codex 须安装 CLI 并完成登录。以 AgentRelay 各引擎的连接检测结果为准。
  3. 在首页确认服务运行，复制根地址，例如 http://127.0.0.1:8787。窗口大小、主题和语言在「外观」中设置；这些选项与引擎连接分开。

02 / 允许扩展连接

只允许你的扩展访问

  1. 在 XFollower 打开「系统设置 → AI 引擎 → 连接帮助」，复制扩展地址；也可从下方复制。
  2. 在 AgentRelay「配置 → 允许的访问来源」点击「添加来源」，填写扩展地址并点击「保存并重启服务」。也可仅向 allowedOrigins 数组追加当前扩展地址，保留其余配置和 Token。
  3. 保存配置后按 AgentRelay 提示重启服务，等待运行恢复；有任务正在生成时先等待任务结束。

这只是字段片段，不能覆盖整个 config.json。不要填 * 或 X.com 网页地址。


03 / 连接与会话
一个连接，三个引擎
  1. 打开「系统设置 → AI 引擎」，填写 AgentRelay 根地址与连接 Token。地址不带 /codex、/grokbot、/antigravity 等路径。
  2. 切换 Grok Bot、Codex 或 Antigravity，点击「读取会话」。三个引擎共用地址与 Token，各自保留会话。
  3. 展开「生成会话」并选择真实标题。长标题可悬停查看；缺少独立标题时显示未命名会话和标识，不用正文伪造标题。
  4. Grok Bot 使用已有 Bot；Codex 与 Antigravity 可填写「新会话」名称再创建。创建会话不等于连接已通过测试。


04 / 测试与保存
收到完整回复后才算成功
  1. 选择专用验收会话，点击「测试并保存」。这会发送一条真实验证消息，使用相应账号额度。
  2. 等待完整回复，不重复点击。显示「测试通过，连接和会话已保存」后关闭并重开设置，核对引擎、会话及已验证状态。
  3. 修改地址、Token 或更换引擎后重新检测。系统设置选择的是该引擎默认会话，具体业务还需核对自己的会话设置。


05 / 业务入口
每项任务选择自己的会话
  • 关注队列 → Grok 创作设置：打开评论开关，选择 AI 引擎和生成会话，保存配置。
  • 首页跟评 → 设置：采集与打标、首页跟评分别选择引擎及会话，保存后重开核对。
  • 知识库 → 设置：选择自动学习使用的 AI 引擎与生成会话，保存后重开。
  • 切换引擎后需重新选择对应会话。开启连接不会自动开启发布，公开发布仍受各业务的开关控制。


任务恢复与升级
任务保留原地址、引擎、会话及任务编号。关闭面板、切换引擎或服务重启后，应先查询原任务；待确认不代表失败，不重复发送。升级 AgentRelay 前等待任务结束，按对应正式发行说明更新并保留本地配置、任务与数据。截图和求助时隐藏 Token、私密路径和业务正文。


遇到问题
现象检查方法
无法连接核对服务运行、根地址、端口和浏览器本机访问授权。8787 是默认值，以当前服务显示为准。
401核对当前 AgentRelay 连接 Token，勿使用旧实例或其他密钥。
403核对 allowedOrigins 中的扩展地址，更新配置后按提示重启。
引擎暂不可用检查对应客户端登录状态及 AgentRelay 引擎检测，不盲目重新发送。
会话为空或标题变化重新读取；核对引擎和会话是否仍存在。标题可以改名，实际选择以会话 ID 绑定。
测试等待或待确认在 AgentRelay 查看原任务和原会话，保留任务编号继续查询。
