# XFollower · 粉丝跟进 · v4.6.2

管理 X 粉丝、待回关账号和关注任务，追踪帖子与作者，使用 Grok、Grok Hook 或本地 Grok Bot 辅助创作与发布。

4.6.2 新增互粉评论：首页采集与批量AI打标、已打标帖子评论分别调度，支持独立AI引擎/Bot、随机间隔、来关必回、随机标签和发布回溯。按账号保存采集锚点，最多保留最新1000条；设置持久化并回读确认。修复点击设置图标后提示残留、表情图片导致评论核验误判，以及批量操作失败详情过早消失的问题。

写作知识统一为“批量分析—经验—当前智慧”，生成按知识库开关读取当前智慧；包含关注队列计划恢复、批量重试、蓝V筛选和会话核验等已集成改进。
