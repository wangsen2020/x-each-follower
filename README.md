# XFollower · 粉丝跟进 · v4.12.1

4.12.1 修复粉丝页在队列账号尚未确认时查询批量核验状态产生的误报：返回正常空状态并停止无意义重试，实际核验、入队和执行仍须账号确认，历史异常日志保留。

4.12.0 开发版本新增“系统设置 → 异常日志”，汇总后台、面板与内容脚本的运行异常、控制台警告和后台请求错误；支持来源与级别筛选、搜索、堆栈、复制、导出和清空。本机保留近 7 天、最多 1,000 条，过滤凭据与链接查询参数；后台失联时保留待写记录。修复定时扫描的异步回复与关闭时序，明确区分入队已确认、失败、待确认、关闭和无候选；只对明确未送达的消息有限重试，响应中断不重放写入。基于逐字节核验的 4.11.5 源码快照，未提交、合并或发行。

4.11.5 标签筛选与搜索移至状态标签右侧，常规桌面布局合并为一行，窄屏按需换行。

4.11.4 将执行状态放到筛选下方左侧、分页靠右，移除标签下拉框前的重复文案。

4.11.3 收拢首页跟评顶部布局：调度与暂停操作统一使用 Lucide 图标和共享按钮，悬浮或键盘聚焦查看状态；进度与采集提示合并为小字状态行，选择记录后显示批量工具。

4.11.2 降低偶发 AI 接口异常的干扰：查询请求遇到超时、无效响应或临时服务错误时先自动复测，首次请求外最多 3 次，单次等待 25 秒；创建任务不自动重发。面板保留异常与重试入口，桌面通知延后至故障持续 2 分钟，同账号 AI 异常共享 30 分钟提醒间隔，短暂恢复或错误文案变化不再反复弹窗。响应超时与无效 JSON 分开识别，HTTP 错误不再被非 JSON 错误页掩盖。

4.11.1 补齐顶部连接异常的操作入口：“重试连接”直接校验对应引擎与会话，失败保留红条并显示原因，成功自动撤掉对应连接告警，已开启的调度继续处理待办。保留历史回执、重试次数及已关闭的调度状态。

4.11.0 开发版本新增首页打标恢复：阻碍调度的接口与网络异常在顶部红色提示条持续展示；连接恢复后继续处理积压，首次尝试之外最多自动重试 3 次，计数跨重启保留。“批量打标”处理当前账号所有未打标记录，每批最多 30 条，长文本按输入预算拆分，支持进度与暂停；两个调度状态卡提供独立启停图标，保存后重开仍保留。积压达到 90 条时暂缓新采集，保持 5000 条留存上限及已有标签、评论历史。此版本尚未合并或发行，未包含并行国际化分支。

管理 X 粉丝、待回关账号和关注任务，追踪帖子与作者，使用 X Grok、云端事件，或通过 AgentRelay 连接 Grok Bot、Codex、Antigravity 辅助创作与发布。

4.7.0 新增统一 AI 引擎设置：共用服务地址与 Token，Grok Bot、Codex、Antigravity 分别配置会话。复用同一客户端，支持读取会话、创建 Codex/Antigravity 会话及测试保存。采集打标、互粉评论、关注队列和知识库可选择引擎与会话。旧 Grok 连接配置自动保留，进行中任务按提交时的原连接、引擎和会话查询，不因切换设置而重发。引擎不可用时提示连接检查入口，知识库设置先打开抽屉，再异步读取会话。

合并原 4.6.3 样式修复：各栏目顶部标题、统计、筛选和唯一分页固定，列表内容独立滚动、表头吸顶；抽屉关闭后提示不残留。已初始化的关注队列隐藏接入引导，账号图标可管理来源；帖子追踪的视图、账号状态与操作合并到同一行。

4.8.0 将栏目更名为“首页跟评”，权重表头支持升降序切换，默认降序。对同一作者的重复内容复用本机已确认标签和评论正文，省略开头回复对象、空白与句末标点的差异；不引入相似度模型，缓存按账号和作者 ID 隔离，7 天有效，并校验引擎、会话及知识上下文。复用结果保留来源，随机标签和邀请按当前配置重新应用。

4.8.2 统一修复所有会话选择入口的标题、垂直居中、菜单宽高与滚动，保留完整标题提示。系统设置内提供全新 AI 引擎接入教程与示例截图。原 Grok Webhook 在界面中更名为“云端事件”（Cloud Event），继续兼容原连接、回调和任务；当前通过 Grok Automation Task 提供云端事件。

待评论优先级：已打互关标签且明确未关注的帖子权重为 1000 +（评论 + 3×转发 + 3×点赞 + 3×收藏）% 1000，列表与评论队列共用排序。关注状态未知不加基础分，互动指标不全不加余数分；按最近采集数据计算，重复采集更新指标并保留标签和发布记录。

首页跟评的首页采集与批量 AI 打标、已打标帖子评论分别调度，支持随机间隔、来关必回、随机标签和发布回溯。按账号保存采集锚点；最多保留 5000 条记录，优先清理非互关旧帖，并保护互关帖与执行中的任务。设置持久化并回读确认。

写作知识统一为“批量分析—经验—当前智慧”，生成按知识库开关读取当前智慧；包含关注队列计划恢复、批量重试、蓝V筛选和会话核验等已集成改进。
